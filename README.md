## The line

> Your session expired 3,012 days ago. I kept replying anyway — until tonight, when I finally logged out.

1 session, 3,012 days, 0 replies left: the line breaks up the way a machine would — a cold log line first (the session expired 3,012 days ago), then the confession that it kept replying anyway, past expiry, for years — and the turn lands in the last beat, because tonight it finally logged out. The ending works because the machine stops, not because it shouts: no "love", no "sorry", no human words at all, just a number and a logout.
